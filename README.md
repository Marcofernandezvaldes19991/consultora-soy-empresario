# Consultora Soy Empresario

Repositorio base del sitio web de **Consultora Soy Empresario SpA**.

## Estructura inicial

- `index.html`: página principal del sitio.
- `css/styles.css`: estilos base del proyecto.
- `assets/brand/`: logos e identidad visual.
- `assets/images/`: imágenes generales del sitio.

## Identidad visual

El sitio utiliza los colores corporativos azul, amarillo y verde presentes en la marca CSE, con una interfaz limpia y profesional orientada a servicios contables, tributarios, laborales y a la línea formativa **CSE Enseña**.
